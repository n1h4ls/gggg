## Verification
- After ANY code change, run the app/tests and confirm it works BEFORE TELLING ME YOU ARE DONE.
- If it fails, fix it and re-verify. Repeat until It passes.
- Never claim somethihng works without having run it.

## Git discipline
- Commit after EVERY logical change with a descriptive messag (e.g. "Add per-category totals to summary view").
- Never mix unreleated changes in one commit.
- Before starting a new task, make sure the working tree is clean.
- After finishing a task, show me  `git log --online -5`.
