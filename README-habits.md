# Habit Tracker

Simple habit tracker added to the workspace.

Files:
- `habits.html` — UI for adding habits and marking today's completion
- `habits.css` — Styles
- `habits.js` — Logic using `localStorage`

Usage:
Open `habits.html` in a browser and add habits. Click the checkbox to mark a habit as done for today. Data is stored locally in your browser's `localStorage`.

Features added:
- Rename a habit by clicking the `Rename` button.
- Current streak calculation (consecutive days completed) shown per habit.
- Weekly summary showing how many times each habit was completed in the last 7 days and current streaks.
