# Personal Task Tracker

A simple browser-based task tracker to create, manage, and review tasks with due dates, reminders, categories, tags, priority levels, and a calendar overview.

## Features
- Create tasks with title, description, due date/time, category, tags, and priority
- Mark tasks as complete or pending
- Filter tasks by search, category, priority, and status
- Calendar view showing due tasks and priority breakdown per day
- Upcoming reminder banner for tasks due soon
- LocalStorage persistence

## Usage
1. Open `index.html` in your browser.
2. Click `New Task` to add a task.
3. Use filters to narrow tasks and inspect the calendar view.
